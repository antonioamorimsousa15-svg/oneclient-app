# Afleck Patch 76 — identidade visual inspirada nas referências

Este patch atualiza os arquivos de interface do Afleck Launcher para aproximar o visual das quatro gravações fornecidas, mantendo a identidade Afleck:

- Tema padrão Afleck Neon: azul-noite, contornos cobre e botões âmbar/coral.
- Fundo espacial estático com estrelas e névoa azul discreta, sem loop de animação.
- Cartões, painéis e navegação preservam o HUD de vidro escuro e cantos arredondados já implementados no patch 75.
- Migração de tema `rev 3` aplica o novo tema padrão em instalações que já usaram o tema antigo.
- Não adiciona marcas ou nomes de terceiros.

Aplicar sobre a mesma árvore-base compatível com o Patch 75. Este ZIP é um patch de fontes/recursos, não um APK nem um projeto Android completo.
