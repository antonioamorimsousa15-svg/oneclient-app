# AFLECK LAUNCHER — r1.0.0 (primeira versão oficial)

Launcher de Minecraft Java para Android, com interface própria em vidro/HUD.
Baseado no ZalithLauncher 2 (GPLv3), com agradecimento em Sobre.

## Novidades
- Interface própria Afleck: menu lateral, barra superior, painéis de vidro HUD e temas de cores.
- Fundo aurora e animação de entrada (fade-in) no menu.
- Player de música: Spotify Web dentro do launcher e do jogo, com cartão flutuante arrastável.
- Telas redesenhadas: Sobre, Java, Renderizador e Idiomas.
- Layouts de HUD, guarda-roupa de skins e atalhos personalizáveis no Início.
- Desempenho: menos uso de RAM, GPU e CPU; argumentos da Java ajustados; versões otimizadas.
- OpenGL/ANGLE atualizados; renderizadores e APIs mantidos.
- Licença Afleck (AFLECK-LICENSE.md) e licença GPLv3 do ZL2 incluídas.
